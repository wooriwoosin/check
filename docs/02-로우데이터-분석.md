## 4. 🎯 결합 검수 — 이관 대상 274건 전수 판정

### 4-0. ⚠️ 검수 범위: 단독만이 아니라 **이관 대상 전체**

**셋트유형(DPS/단독)과 결합 요청은 서로 다른 축입니다.**

- `DPS` = **유선끼리** 묶음 (인터넷 + TV 동시가입)
- **모바일결합 / 유선전화결합** = 기존에 쓰던 회선을 붙이는 것 — DPS든 단독이든 발생

실제로 결합대상 13명 중 **9명이 DPS**입니다. **단독만 보면 대부분 놓칩니다.**

### 4-1. 검수 대상 정의

**"기존에 쓰던 회선을 유선신규에 붙여달라"** 는 요청. 두 가지뿐입니다.

| 유형 | 내용 |
|---|---|
| **유형1 — 유무선결합** | **지금 쓰고 있는 KT 휴대폰**이 있고, 유선신규 가입하면서 결합 요청<br>**KT망 알뜰폰도 대상** (우리가 묶어줘야 함) |
| **유형2 — 유선전화 결합** | **기존에 쓰던 KT 일반전화(02·0XX)/인터넷전화(070)** 가 있고, 유선신규 가입하면서 결합 요청 |

### ❌ 검수 대상이 아닌 것

| 제외 | 이유 | 라인 |
|---|---|---|
| **`모바일_KT` 동시가입 고객** | 유선·무선 **동시** 가입 → **별도 검수 프로세스** | 51 |
| **패밀리 계열** (`패밀리슬림/베이직/에센스`, `결합: 패밀리`) | **유선 + 유선** 결합이라 KT전산 로우데이터로 확인 불가 | 12 |
| **향후 결합 예정** (`결합: 결합예정`, `나중에 총액결합 예정`) | 아직 KT 휴대폰이 없음 | 4 |
| **`고객별도진행` / `고객센터 안내`** | 고객이 직접 처리 → **우리가 안 걸어줌** | 3 |
| **타사 결합상품** (`요즘 가족 결합`) | SK 상품 | 3 |

> 유형2(유선전화 결합)는 **휴대폰 통신사와 무관**하므로 마지막 규칙을 타지 않습니다.
> (r459 김희선 — 휴대폰은 SK인데 기존 유선전화 결합이라 대상)

### 4-2. ⚠️ 결합 신호를 가리는 노이즈 4종 — 반드시 먼저 제거

노이즈 제거 없이 `결합` 글자만 찾으면 **오탐이 절반 이상**입니다.

| 노이즈 | 실제 예시 | 정체 |
|---|---|---|
| **서식지 항목명** | `□월요금/모바일 결합 할인금액: 23,100` | 결합 안 해도 **항상** 있는 라벨 |
| **서식지 보기목록** | `· 결합유형 (프가=1/ 프싱=2/ 총액=3/ 정액=4/ 신혼미리결합=5) :1` | 상품명이 **전부** 나열됨.<br>실제 값은 뒤의 **`:1`** → 프리미엄가족결합 |
| 청구·인증·사은품 | `■청구매체: 모바일`, `■본인인증: 모바일 인증`, `이마트모바일 3만원` | 결합과 무관 |
| **해지 대상 회선** | `전통신사 : LGU+ 070-8633-6695  SKB 031-873-9018` | **이전 통신사** 번호. 결합이 아니라 **해지** 대상 |

> **`전통신사` 줄**을 안 빼면 타사 유선번호를 "기존 KT 전화"로 오인합니다.

## 5. 🔴 가입.번호(H)의 `z!` 마커 — 기존 매크로가 놓치는 부분
