## 4. 🎯 KT 유선 단독 79건 판정 결과

### 4-0. 검수 대상 정의 (확정)

**검수하려는 결합은 "기존에 쓰던 회선을 유선신규에 붙여달라"는 건**입니다. 두 가지뿐입니다.

| 유형 | 내용 |
|---|---|
| **유형1 — 유무선결합** | 고객이 **지금 쓰고 있는 KT 휴대폰**이 있고, 유선신규 가입하면서 결합 요청 |
| **유형2 — 유선전화 결합** | 고객이 **기존에 쓰던 KT 일반전화(02·0XX)/인터넷전화(070)** 가 있고, 유선신규 가입하면서 결합 요청 |

### ❌ 검수 대상이 아닌 것 (제외)

| 제외 | 이유 |
|---|---|
| **패밀리 계열** (`패밀리슬림/베이직/에센스`, `결합: 패밀리`, `패밀리결합`) | **유선 + 유선** 결합이라 KT전산 로우데이터로 확인할 수 없음 |

## 5. 🔴 가입.번호(H)의 `z!` 마커 — 기존 매크로가 놓치는 부분

KT 유선 356건 중 가입번호가 있는 **299건 전부에 `z!` 접두사**가 붙어 있습니다.
그리고 숫자뭉치가 **2개 이상**인 행이 30건 있습니다.

```
정상    z!68251418660 / 051-034-3526          → 서비스번호 + 전화번호
2개     61250677816/Z!67253719883 / 02-...    → 인터넷계약번호 + ★서비스번호 + 전화번호
                    ↑ z! 가 붙은 쪽이 진짜
```

**`z!` 가 뒤에 오는 24건**을 매크로는 앞 번호로 잘못 매칭합니다.

특히 위험:
```
r15  63250668734/z!63250669162/031-117-9227
     63250668  vs  63250669   ← 앞 8자리가 1 차이. 같은 고객의 다른 회선
```

### 그 외 가입번호 이슈

| 이슈 | 건수 | 처리 |
|---|---|---|
| 가입번호 **비어있음** | 57 | 취소완료 31 / 보류 19 → 검수제외. **접수완료 3 + 개통완료 1 은 오류** |
