# 04. 사용법

## 전체 흐름

```
① 웹 어드민에서 전체고객상품 다운로드
        ↓
② 1차 웹 검수 (브라우저)  ← 이 도구
   · KT전산 이관 대상만 필터링 (979 → 274)
   · 결합대상 감지, 개통기한·상부점·판매점·OSS·상품매핑·가입번호 점검
   · 제외 데이터를 뺀 이관 파일(.xlsx) 생성
        ↓
③ 이관 파일을 KT전산(VPN)으로 반입
        ↓
④ KOS 데이터 3종을 붙여넣기 → 2차 검수 자동 계산
```

---

## 1차 웹 검수 (브라우저)

주소를 열고 **`전체고객상품(YYYYMMDDHHMM).xls`** 를 끌어다 놓으면 끝입니다.

**해피콜 전체고객상품목록**도 같이 올리면 **상품권 메모 검수**가 추가됩니다 (선택).
해피콜 목록에는 `접점코드`·`사업자번호` 가 없어서 기본 파일을 대체하지는 못합니다 —
자세한 차이는 [06-로우데이터-2종-비교.md](06-로우데이터-2종-비교.md) 참고.

> 파일은 **브라우저 안에서만** 처리됩니다. 서버로 올라가지 않고, 인터넷 연결도 필요 없습니다.
> (페이지를 한 번 연 뒤에는 오프라인에서도 동작합니다)

### 화면 구성

| 카드 | 뜻 |
|---|---|
| 전체 행 | 받은 파일의 전체 행 수 |
| KT전산 이관 대상 | 필터를 통과해서 넘어갈 건 |
| 이관 제외 | 타 통신사 / 업셀링·약정갱신 / 대성 상부점 |
| **결합대상 (고객)** | **전산 넘기기 전에 결합을 걸어줘야 하는 고객** |
| 결합 확인필요 (고객) | 사람이 한 번 봐야 하는 건 |
| 1차 검수 지적 | 개통기한·상부점·판매점·OSS·상품매핑·가입번호 |

### 탭별 점검 항목

| 탭 | 무엇을 보나 |
|---|---|
| **결합대상** | 기존 KT 휴대폰(유형1) 또는 기존 KT 일반·인터넷전화(유형2) 결합 요청<br>※ **동판·유심동판은 제외** (유선 개통 후 무선 진행 → 결합이라 별개 건) |
| 결합 확인필요 | 근거가 약하거나 유형이 안 갈리는 건 |
| 개통기한 | 개통기한 ≠ 접수일의 익월 말일 |
| 상부점 | 상부점이 온라인이면 접점코드도 온라인이어야 함 (양방향) + 같은 접점코드인데 상부점이 다른 건<br>※ 도매 하위 접점(24종)이 실제 전산에 맞게 들어갔는지는 **2차**에서 KOS 접점명과 대조 |
| 판매점 접수경로 | 협력점명 `☆★` → 접수경로 협력점 / `□■` → 판매점. 안 맞는 건 |
| **OSS(원스톱전환)** | **웹 원스톱해지 라인 전체 + 원스톱키. KOS 원스톱과 수량 대사용** |
| 상품 매핑 | 상품옵션을 KT 상품명으로 못 바꾸는 건 |
| 가입번호 | 비어있는데 개통상태가 진행 중이거나, 자릿수가 안 맞는 건<br>일반 유선은 **11자리**, 버디AX·복수AP 는 **12자리** |
| **KT 상품권 미등록** | 본인인증이 KT 인데 상품권이 `등록예정` 인 건 — KT 는 바로 등록 가능<br>※ **해피콜 목록을 올려야 검사됩니다** |
| **상품권 메모누락** | 비KT 고객이 `등록예정` 인데 가입.번호에 `★상품권` 메모가 없는 건<br>※ **해피콜 목록을 올려야 검사됩니다** |

> 상품권 두 항목은 개통상태가 **`접수완료`·`실적확인중`·`개통완료`** 인 건만 봅니다 (취소·보류 제외).
| 이관 제외 | 왜 빠졌는지 사유별로 |

> **결합대상은 전산에 넘기기 전에 처리하세요.**
> 전산은 셋트유형이 단독이면 무조건 `결합 X` 로 잡아서, 여기서 못 걸면 놓칩니다.

## 2차 KT전산 검수 (엑셀)

`이관 파일 다운로드` 로 받은 **`KT검수_이관_YYMMDDHHMM.xlsx`** 를 KT전산으로 가져갑니다.

### 붙여넣기

| 시트 | 붙여넣을 자료 | 시작 행 |
|---|---|---|
| `접수` | KOS 접수리스트 | **3행** |
| `결합` | KOS 결합 리스트 | **3행** |
| `원스톱` | KOS 원스톱 | **2행** |

붙여넣는 순간 `웹` 시트와 `OSS대사` 시트가 **자동으로 계산**됩니다.
**매크로 실행 버튼이 없습니다** — 수식이라 붙여넣기만 하면 끝입니다.

> ⚠️ 각 시트 오른쪽 끝의 **보조열은 지우지 마세요.** 매칭 키를 만드는 수식입니다.
> · `접수` AV(키8) AW(전화앞5) AX(상품정규화) AY(복합키) **AZ(웹 매칭여부)**
> · `결합` U(생년월일6)  · `원스톱` Q(서비스번호키) **R(웹 매칭여부)**
>
> 붙여넣기 여유는 2,000행입니다. 더 많으면 보조열 수식을 아래로 끌어 채우세요.

### 결과 보기 — 3군데

| 어디 | 무엇 |
|---|---|
| `웹` 시트 | 웹 기준 검수 — `2차판정` 을 `확인필요` 로 필터 |
| `접수` 시트 **AZ열** | **KOS 에만 있는 접수건** — `웹없음` 으로 필터<br>(기존 매크로의 `웹미존재_접수건` 시트와 같은 역할) |
| **`OSS대사` 시트** | **원스톱 수량 대사** — `차이` 가 0 이어야 정상 |

`웹` 시트에서 **`2차판정`** 열을 `확인필요` 로 필터링하면 볼 것만 남습니다.
**`2차오류사유`** 열에 무엇이 걸렸는지 글자로 적힙니다.

| 2차 검수 열 | 값 |
|---|---|
| 접수검수 | `O` / `상품상이` / `접수없음` / `키없음` / `OSS별도`<br>`OSS별도` 는 원스톱해지 라인 — 접수리스트가 아니라 `OSS대사` 시트로 확인합니다 |
| 접수상태 | KOS 진행상태를 그대로 가져옴 |
| 개통상태검수 | `O` / `불일치` / `확인` |
| 접수접점명 | KOS 접점명 (업체 대조용) |
| 결합검수 | `O` / `결합X` / `해당없음`<br>단독은 1차에서 `결합대상` 으로 잡힌 건만 대조하고, 나머지 단독은 `해당없음`.<br>DPS 는 전산 확인이 필요하므로 전부 대조 |
| 원스톱상태 | KOS 원스톱전환상태 / `원스톱없음` |
| **2차오류사유** | `상품상이` `개통상태불일치` `결합누락` `원스톱미접수` 등 |
| **2차판정** | `정상` / `확인필요` |

### OSS대사 시트

| 줄 | 뜻 |
|---|---|
| 웹 원스톱해지(OSS) 라인 | 1차에서 넘어온 건수 (고정) |
| KOS 원스톱 붙여넣은 행 | `원스톱` 시트에 붙여넣은 건수 (자동) |
| **차이** | **0 이어야 정상** |
| 웹에만 있음 | KOS 에 원스톱 접수가 안 된 건 |

행별로 `원스톱전환상태`·`오더상태` 를 KOS 에서 끌어옵니다. `원스톱없음` 이면 KOS 에 없는 건입니다.
반대로 `원스톱` 시트 **R열**이 `웹없음` 이면 KOS 에만 있는 건입니다.

### 개통상태 매핑

| KOS 진행상태 | 정상인 웹 개통상태 |
|---|---|
| 사용중 | 개통완료 |
| 가설중(예약) | 접수완료 / 실적확인중 / 접수대기 |
| 해지 | 해지(철회)완료 / 해지(철회)중 / 취소완료 |

## 왜 매크로(.xlsm)가 아니라 수식(.xlsx) 인가

기존 매크로가 하던 일을 **전부 엑셀 수식으로 옮겼습니다.** 이유는:

| | 매크로 | 수식 (현재) |
|---|---|---|
| 보안 경고 | 매번 "콘텐츠 사용" 눌러야 함 | 없음 |
| 실행 | 버튼을 눌러야 결과가 나옴 | 붙여넣는 즉시 계산 |
| 검증 | 코드를 봐야 알 수 있음 | 셀을 누르면 수식이 보임 |
| 수정 | KT전산 안에서 VBA 편집 | 수식만 고치면 됨 |
| 결과 | 셀 배경색 → 필터·집계 불가 | 글자 → 필터·집계 가능 |

**매칭 키를 1차(웹)에서 미리 계산해서 열로 넣어주기 때문에** 2차에서 문자열 파싱을 할 필요가 없어졌고,
그래서 VBA 없이도 됩니다. 기존 매크로의 위험한 코드(마지막 4자리 폴백 등)도 통째로 사라집니다.

> 매크로 형태가 꼭 필요하면 알려주세요. 이 수식 파일을 그대로 `.xlsm` 으로 저장하고
> 초기화·서식 같은 편의 기능만 VBA 로 얹는 방식으로 만들 수 있습니다.

## 부가상품 KOS 매핑

`KT_부가상품` 은 KOS 에서 상품명이 갈립니다. 현재 매핑은 이렇습니다.

| 웹 상품옵션 | KOS 상품구분 | KOS 상품군 | KOS 상품명 |
|---|---|---|---|
| `복수AP` | 홈IoT | 복수AP | **WiFi패키지 플러스** |
| `100M+버디AX` `500+버디AX` `1G↑+버디AX` | 홈IoT | 복수AP | **GiGA WiFi Buddy ax** |
| `원스톱해지(OSS)` | — | — | 접수리스트 아님 → `OSS대사` 시트로 확인 |

**상품군은 둘 다 `복수AP` 로 같고 상품명이 갈리므로, 상품명 기준으로 맞춥니다.**

목록에 없는 부가상품이 나오면 속도(`500M` 등)만 보고 인터넷 상품으로 오인하지 않도록
빈값 처리해서 1차 `상품 매핑` 탭에 뜨게 합니다. 그때 `assets/rules.js` 의 `ADDON_MAP` 에 한 줄 추가하면 됩니다.

## 개발자용

| 파일 | 역할 |
|---|---|
| `index.html` | 1차 검수 화면 |
| `assets/rules.js` | **판정 규칙** — 필터·상품정규화·결합판정. 규칙을 바꾸려면 여기만 |
| `assets/app.js` | 웹 로우데이터 파싱 + 1차 검수 실행 |
| `assets/export.js` | 이관 파일 생성 (2차 검수 수식 포함) |
| `assets/xlsx.js` | 의존성 없는 XLSX 생성기 (외부 라이브러리 안 씀) |
| `assets/kos-templates.js` | KOS 양식 헤더 |
| `assets/ui.js` | 화면 구성 |
| `tools/*.py` | 같은 규칙의 파이썬 판 (문서 수치 검증용) |

외부 라이브러리를 하나도 쓰지 않습니다. 사내망에서 CDN 이 막혀도 동작합니다.
