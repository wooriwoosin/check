# KT 검수 도구

우리 어드민 웹 로우데이터와 KT전산(KOS) 데이터를 대조하는 검수 도구입니다.

## 현재 상태

전임자가 만든 엑셀 매크로(`결합접수_검수.xlsm`)를 분석하고, 검수를 2단계로 나누는 작업 중입니다.

```
1차 : 웹 검수 (HTML / GitHub Pages, 사외)     →  2차 : KT전산 검수 (xlsm, VPN 내부)
      웹 로우데이터만으로 판정 가능한 항목            전산 데이터가 있어야만 판정 가능한 항목
      + KT전산으로 넘길 xlsm 생성
```

## 핵심 요약

- 기존 매크로는 **셋트유형(단독/DPS)을 전혀 보지 않아** 단독 49건이 전부 `결합누락` 오탐
- 웹 시트 **헤더가 BB열부터 한 칸 밀려** 있어 사업자번호 기반 결합 매칭이 죽어있음
- 상품 정규화가 **280건 중 36건(12.9%) 오작동** (`TV에센스` 누락, `패밀리` 삭제 등)
- 원스톱(OSS) 검수 로직은 **매크로에 존재하지 않음**
