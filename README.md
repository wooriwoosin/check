# KT 검수 도구

우리 어드민 웹 로우데이터와 KT전산(KOS) 데이터를 대조하는 검수 도구입니다.

## 사용하기

**→ [1차 웹 검수 열기](https://wooriwoosin.github.io/check/)**

`전체고객상품(YYYYMMDDHHMM).xls` 를 끌어다 놓으면 검수 결과가 나오고,
KT전산으로 넘길 파일을 받을 수 있습니다. 파일은 브라우저 안에서만 처리됩니다.

자세한 사용법은 **[04-사용법.md](docs/04-사용법.md)** 를 보세요.

## 구조

```
① 웹 어드민에서 전체고객상품 다운로드
        ↓
② 1차 웹 검수 (브라우저)
   · KT전산 이관 대상만 필터링 (979 → 274)
   · 결합대상 감지 + 웹만으로 되는 검수 6종
   · 제외 데이터를 뺀 이관 파일(.xlsx) 생성
        ↓
③ 이관 파일을 KT전산(VPN)으로 반입
        ↓
④ KOS 데이터 3종 붙여넣기 → 2차 검수 자동 계산 (수식, 매크로 불필요)
```

## 핵심 요약

웹 로우데이터 **979행 전수 검증** 기준, 기존 매크로의 오탐 규모입니다.

| 오탐 원인 | 건수 |
|---|---|
| 이관 대상이 아닌 건이 `접수누락` 으로 찍힘 (979건 중 이관 대상은 274건) | **705** |
| 단독인데 `결합누락` 으로 찍힘 (이관 274건 중 단독 49건, 실제 결합대상은 4라인) | **45** |
| 상품 정규화 실패로 `상품상이` | **약 25%** |
| 가입번호의 `z!` 마커를 무시해 엉뚱한 회선에 매칭 | **24** |
| 상부점 규칙이 값 2개만 인정 | **8** |

그 외:
- 웹 시트 **헤더가 BB열부터 한 칸 밀려** 있어(`고객이력` 열이 실제로는 없음) 사업자번호 결합 매칭이 죽어있음
- 원스톱(OSS) 검수 로직은 **매크로에 존재하지 않음**
- 결합 검수 대상은 **기존 KT 휴대폰 결합(유형1)** 과 **기존 KT 일반전화·인터넷전화 결합(유형2)** 두 가지.
  패밀리(유선+유선)·모바일_KT(동시가입)·고객별도진행은 제외
- **셋트유형과 결합 요청은 별개 축** — DPS 건에도 결합 요청이 들어옴.
  이관 대상 274건 전수 판정 결과 **결합대상 13명(28라인) / 확인필요 2명**,
  이 중 **9명이 DPS**라 단독만 보면 대부분 놓침
- KT전산 이관 필터: 상품명 화이트리스트 7종 + 대성 상부점·접점 제외 → **979건 → 274건**
  (기존 매크로 웹 시트의 280행과 거의 일치 — 손으로 거르던 범위와 같음)
