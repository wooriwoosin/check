# KT 검수 도구

우리 어드민 웹 로우데이터와 KT전산(KOS) 데이터를 대조하는 검수 도구입니다.

## 현재 상태

전임자가 만든 엑셀 매크로(`결합접수_검수.xlsm`)를 분석하고, 검수를 2단계로 나누는 작업 중입니다.

```
1차 : 웹 검수 (HTML / GitHub Pages, 사외)     →  2차 : KT전산 검수 (xlsm, VPN 내부)
      웹 로우데이터만으로 판정 가능한 항목            전산 데이터가 있어야만 판정 가능한 항목
      + KT전산으로 넘길 xlsm 생성
```

## 핵심 요약

웹 로우데이터 **979행 전수 검증** 기준, 기존 매크로의 오탐 규모입니다.

| 오탐 원인 | 건수 |
|---|---|
| 타 통신사 건이 `접수누락` 으로 찍힘 (KT는 979건 중 408건뿐) | **571** |
| 단독인데 `결합누락` 으로 찍힘 (단독 79건 중 실제 결합대상은 5건) | **74** |
| 상품 정규화 실패로 `상품상이` (KT유선 356건의 25.0%) | **89** |
| 가입번호의 `z!` 마커를 무시해 엉뚱한 회선에 매칭 | **24** |
| 상부점 규칙이 값 2개만 인정 | **8** |

그 외:
- 웹 시트 **헤더가 BB열부터 한 칸 밀려** 있어(`고객이력` 열이 실제로는 없음) 사업자번호 결합 매칭이 죽어있음
- 원스톱(OSS) 검수 로직은 **매크로에 존재하지 않음**
- `모바일_KT` 라인의 `약정` 컬럼이 결합 판정의 가장 확실한 신호인데 안 쓰고 있음
